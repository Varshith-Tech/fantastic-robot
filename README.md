# P. V. Varshith — 3D Portfolio

A responsive, single-page portfolio built with HTML, CSS, JavaScript and Three.js (loaded from jsDelivr).

## Run locally

Because the 3D scene uses JavaScript modules, serve this folder over HTTP rather than opening the file directly:

```bash
cd varshith-3d-portfolio
python -m http.server 8000
```

Then visit http://localhost:8000.

## Before publishing

1. Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email address.
2. Add verified LinkedIn, GitHub and project links.
3. Replace concept project descriptions with actual outcomes, screenshots, repositories and measurable impact.
4. Add a real CV file if you want a resume download link.

The animated Three.js background is decorative and automatically disabled when the visitor requests reduced motion. The layout remains responsive and usable without WebGL.
